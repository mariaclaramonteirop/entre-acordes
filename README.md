# Entre Acordes

Site institucional da **Entre Acordes**, uma assessoria musical especializada em cerimônias, casamentos, eventos e celebrações. A plataforma apresenta a equipe, os serviços oferecidos, uma galeria de momentos especiais, dicas musicais e canais de contato.

## Demonstração

🔗 [Acessar o projeto no GitHub](https://github.com/mariaclaramonteirop/entre-acordes)

## Sobre o projeto

A Entre Acordes nasceu para transformar celebrações em experiências ainda mais marcantes por meio da música ao vivo. O site foi desenvolvido com uma identidade visual elegante, acolhedora e alinhada à proposta da marca.

O projeto conta com páginas institucionais e recursos interativos para facilitar a navegação e aproximar os visitantes da equipe musical.

## Funcionalidades

- Página inicial com apresentação da assessoria musical;
- Seção de serviços para cerimônias religiosas, cerimoniais civis, recepções e eventos especiais;
- Galeria de fotos com carrossel responsivo;
- Visualização das imagens em tela cheia com modal lightbox;
- Página com a história e os integrantes da equipe;
- Página de indicações com playlists e dicas para celebrações;
- Página de perguntas frequentes com accordion interativo;
- Página de contato;
- Menu responsivo para dispositivos móveis;
- Integração de contato e solicitação de orçamento pelo WhatsApp;
- Links para redes sociais e Spotify.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript;
- Google Fonts;
- Spotify;
- WhatsApp.

## Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/mariaclaramonteirop/entre-acordes.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd entre-acordes
   ```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto com atualização automática durante o desenvolvimento.
